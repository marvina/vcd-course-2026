# 视觉传达设计学院 · 课程教学周历系统 (2026-2027-1)

视觉传达设计学院 2026-2027 学年第一学期专业课程周历可视化与教学管理系统。

## 🌟 核心特性

- **多层次年级全覆盖**：支持本科生（大一至大四：2026级、2025级、2024级、2023级）与硕士研究生（2026级研一、2025级研二）全专业课表。
- **动态周历交互**：支持 1–20 周任意周次快速切换与进度透视，区分国庆假期、考查周与学术讲座周。
- **全学期穿透检索**：支持跨越所有年级、周次与专业的全局检索（按课程名、教师名、班级、教室、专业方向即时搜索高亮）。
- **教学空间布局**：整合 5 楼专业工作室（507–530）、2号教学楼及专业实验室占用状态监测与利用率统计。
- **移动端与响应式适配**：支持密集/适中/宽松密度切换、主题色切换以及课程详情弹窗甘特图展示。

## 📁 核心文件结构

- `index.html`: 主看板与交互式周历界面（完整内嵌交互系统与全部课程数据库）
- `svcd.png`: 视觉传达设计学院标志
- `teacher_photos/`: 全院教师头像资源库

## 🚀 部署与访问

支持直接托管至 GitHub Pages 或任何静态 Web 服务器。
入口文件为 `index.html`。
